# Hugim OS — פלטפורמת ניהול חוגים (שם עבודה)

מוצר SaaS רב-דיירי לניהול עסק חוגים — מתחרה ל-TAZMAN, ממוקד ב**חוגים**: רישום אונליין, גבייה אוטומטית והוראות קבע, נוכחות, תקשורת WhatsApp, אפליקציית הורה/מדריך, דוחות ו-BI, ושכבת AI.

## מיצוב ובידול
מוצר **מודרני, אוטומטי ומבוסס-AI** עם שלושה צירי בידול מרכזיים:
1. **חוויית הורה/לקוח** — רישום ותשלום ב-60 שניות מהנייד, ללא שיחות טלפון.
2. **אוטומציה ו-AI** — גבייה, תזכורות, רשימות המתנה, חידושים וסוכן שירות על טייס אוטומטי.
3. **ניהול, דוחות ו-BI** — דשבורד מנהל, תחזית הכנסות, churn, רווחיות per-חוג.

לא מתחרים על מחיר.

## סטאק
- **Frontend:** Next.js (App Router) + TypeScript + Tailwind (RTL) + shadcn/ui
- **Backend/Data:** Supabase (Postgres + RLS multi-tenancy, Auth, Storage, Realtime, Edge Functions)
- **Infra:** Vercel + Supabase managed
- **אינטגרציות:** סולק IL (Tranzila/Cardcom/PayPlus/Meshulam), ספק חשבוניות (חשבונית ירוקה/Morning), WhatsApp Business API (BSP), Claude API ל-AI
